Build beautiful script UIs with Aether

A frosted-glass Roblox UI library with springy animations, a command palette, pinnable widgets, configs, themes and a drop-in Rayfield compatibility layer. Readable source, no telemetry: Aether never makes network requests on its own.

10 built-in elements 7 themes Configs & share codes Ctrl + K palette Touch friendly Rayfield compatible
ChainableEvery method returns itself, so you can write Tab:Button("Hi"):OnClick(fn).
Auto-savingEvery value is saved automatically, keyed by its flag or by Tab/Section/Name.
Pin anythingDrag an element out of the window to get a floating widget that stays in sync.
AccessibleReduced motion mode, keyboard toggle key and fit-to-screen scaling.

Installation

Load the library with loadstring in your executor, then create a window.

local Aether = loadstring(game:HttpGet("https://raw.githubusercontent.com/RedScaleR/Aether/main/Aether.lua"))()

local Window = Aether:Window({ Name = "My Script", Subtitle = "v1.0" })

That's all you need. The window shows itself automatically once your tabs are in place. Press RightControl to hide or show it.

Full example

A complete script using most of the library. Copy it, paste it into your executor, and start tweaking.

local Aether = loadstring(game:HttpGet("https://raw.githubusercontent.com/RedScaleR/Aether/main/Aether.lua"))()

local Players = game:GetService("Players")
local LocalPlayer = Players.LocalPlayer

local function humanoid()
    local character = LocalPlayer.Character
    return character and character:FindFirstChildOfClass("Humanoid")
end

local Window = Aether:Window({
    Name = "Aether Hub",
    Subtitle = "v1.0",
    Icon = "sparkles",
    Theme = "Aether",
    ToggleKey = "RightControl",
})

---------------------------------------------------------------- Player tab
local Player = Window:Tab({ Name = "Player", Icon = "user" })

Player:Section("Movement")

Player:Slider({
    Name = "WalkSpeed",
    Min = 16, Max = 200, Default = 16, Increment = 1,
    Suffix = " studs",
    Flag = "WalkSpeed",
    Callback = function(value)
        local h = humanoid()
        if h then h.WalkSpeed = value end
    end,
})

Player:Slider({
    Name = "JumpPower",
    Min = 50, Max = 300, Default = 50,
    Flag = "JumpPower",
    Callback = function(value)
        local h = humanoid()
        if h then h.JumpPower = value end
    end,
})

Player:Toggle({
    Name = "Infinite Jump",
    Description = "Jump again while in the air",
    Keybind = "J",
    Flag = "InfJump",
})

game:GetService("UserInputService").JumpRequest:Connect(function()
    if Aether.Flags.InfJump then
        local h = humanoid()
        if h then h:ChangeState(Enum.HumanoidStateType.Jumping) end
    end
end)

Player:Section("Server")

Player:Button("Rejoin")
    :Description("Reconnects to this server")
    :OnClick(function()
        game:GetService("TeleportService"):Teleport(game.PlaceId, LocalPlayer)
    end)

---------------------------------------------------------------- Visuals tab
local Visuals = Window:Tab({ Name = "Visuals", Icon = "eye" })

Visuals:Toggle({ Name = "ESP", Flag = "ESP" })

Visuals:ColorPicker({
    Name = "ESP color",
    Default = Color3.fromRGB(139, 92, 246),
    Flag = "ESPColor",
})

Visuals:Dropdown({
    Name = "ESP mode",
    Options = { "Box", "Highlight", "Name only" },
    Default = "Highlight",
    Flag = "ESPMode",
})

---------------------------------------------------------------- Misc tab
local Misc = Window:Tab({ Name = "Misc", Icon = "settings-2" })

local status = Misc:Label("Status: idle")

Misc:Input({
    Name = "Message",
    Placeholder = "Type something...",
    Callback = function(text)
        status:SetText("Status: you typed " .. text)
        Aether:Notify({ Title = "Got it", Content = text, Type = "Success" })
    end,
})

Misc:Keybind({
    Name = "Panic",
    Default = "P",
    Callback = function()
        Aether:Unload()
    end,
})

---------------------------------------------------------------- Built-in settings
Window:SettingsTab()

Aether:Notify({ Title = "Loaded", Content = "Press RightControl to toggle the UI.", Type = "Info" })

Calling styles

Every constructor (Window, Tab, Section and every element) accepts either an options table, a name string, or a name string followed by an options table. These three lines are equivalent:

Tab:Toggle({ Name = "Fly", Default = true })
Tab:Toggle("Fly", { Default = true })
Tab:Toggle("Fly"):Set(true)

Friendly aliases from other libraries also work: Title is accepted for Name, and Desc for Description.

Every element method is also available with a Create prefix (Tab:CreateToggle, Tab:CreateSlider…). Those keep Rayfield's callback shapes, see Rayfield compatibility.

Window

The main frosted-glass window with a topbar, sidebar tabs, dragging, resizing and fit-to-screen scaling. Create one with Aether:Window(options) (alias Aether:CreateWindow).

local Window = Aether:Window({
    Name = "My Script",
    Subtitle = "by me",
    Icon = "sword",
    Size = Vector2.new(680, 460),
    Theme = "Midnight",
    ToggleKey = "RightShift",
    AutoSave = true,
})

Iconstring | numberLogo icon: a Lucide name, an asset id or an rbxassetid:// string.
SizeVector2 | UDim2Window size in pixels. Default 680×460 (580×340 on touch). Minimum 400×300.
Themestring | tableA theme name (see Themes) or a table of colors.

Tab

A sidebar entry and its scrolling page. Without an icon (or with an unknown one), the tab shows its initial in a small badge.

local Main = Window:Tab({ Name = "Main", Icon = "home" })
local Combat = Window:Tab("Combat", { Icon = "sword" })

Main:Button("Hello")   -- elements can be added straight onto a tab
Combat:Select()        -- switch to this tab
Option / MethodDescription
NameTab name. Default "Tab N".
IconLucide icon name or asset id.
Tab:Section(options)Creates a section. Alias CreateSection.
Tab:Select()Switches the window to this tab.
Tab:SetVisible(visible)Shows or hides the tab in the sidebar.
Tab:Destroy()Removes the tab and everything in it.

Section

A titled card that groups elements. Elements created directly on a tab go into its most recent section, and an untitled section is made automatically if there is none.

local Movement = Main:Section("Movement")
Movement:Toggle("Fly")
Movement:Slider({ Name = "Fly speed", Min = 1, Max = 10 })

-- Or keep adding to the tab: these land in the latest section.
Main:Section("Teleports")
Main:Button("Spawn")
Main:Button("Shop")
MethodDescription
Section:SetName(name)Renames the section. Alias Set.
Section:SetVisible(visible)Shows or hides the whole section.
Section:Destroy()Removes the section and its elements.

Common element API

Every element shares these options and methods. All methods return the element, so they can be chained.

Shared options

OptionTypeDescription
NamestringTitle shown on the row.
DescriptionstringSmaller text under the title.
CallbackfunctionRuns when the value changes (or the button is pressed).
FlagstringStores the value in Aether.Flags[flag]. Also the config id.
TooltipstringText shown when hovering the element.
DisabledbooleanStarts disabled.
DisabledReasonstringTooltip shown while disabled.
Visiblebooleanfalse starts hidden.
Savebooleanfalse keeps this element out of configs.

Shared methods

MethodDescription
:OnChanged(fn)Adds another change handler.
:SetTitle(text)Changes the title.
:SetDescription(text)Changes the description. Alias :Description(text).
:Tooltip(text)Sets the hover tooltip.
:Flag(name)Sets or changes the flag.
:SetVisible(visible)Shows or hides the element.
:SetDisabled(disabled, reason)Greys the element out and blocks input.
:Reset()Goes back to the default value.
:Pin(position) / :Unpin()Turns the element into a floating widget (Pinnable elements).
:Flash()Briefly highlights the row.
:GetId()The flag, or "Tab/Section/Name".
:Destroy()Removes the element.

Elements also expose element.Value and a element.Changed signal.

local godMode = Tab:Toggle("God mode")
    :Description("Can't take damage")
    :Tooltip("Only works in some games")
    :Flag("GodMode")
    :OnChanged(function(on)
        print("God mode:", on)
    end)

godMode:SetDisabled(true, "Not supported in this game")
Right-click an element (or long-press on mobile) to open its menu: pin to screen, copy value, reset, add a key bind and more.

Button

Runs a function when clicked. Can have a key bind.

Tab:Button({
    Name = "Rejoin",
    Description = "Reconnects to this server",
    Callback = function()
        game:GetService("TeleportService"):Teleport(game.PlaceId)
    end,
})

-- Chained style, with a key bind:
Tab:Button("Reset character"):OnClick(function()
    game.Players.LocalPlayer.Character:BreakJoints()
end):Keybind("R")
Option / MethodDescription
KeybindKey that presses the button, e.g. "R".
:OnClick(fn)Adds a click handler.
:Press()Presses the button from code.
:Set(text)Changes the button text.
:Keybind(key) / :GetKeybind()Sets or reads the key bind.

Toggle

An on/off switch. The callback receives a boolean.

local fly = Tab:Toggle({
    Name = "Fly",
    Default = false,
    Keybind = "F",
    Flag = "Fly",
    Callback = function(on)
        print("Fly is now", on)
    end,
})

fly:Set(true)     -- turn it on (fires the callback)
fly:Toggle()      -- flip it
print(fly:Get())  -- current state
Option / MethodDescription
DefaultStarting state. Default false. (Also Value, CurrentValue.)
KeybindKey that flips the toggle.
:Set(value, silent)Sets the state. silent = true skips the callback.
:Toggle()Flips the state.
:Get()Returns the state.
:Keybind(key) / :GetKeybind()Sets or reads the key bind.

Slider

Pick a number in a range.

local speed = Tab:Slider({
    Name = "WalkSpeed",
    Min = 16,
    Max = 200,
    Default = 16,
    Increment = 1,
    Suffix = " studs",
    Callback = function(value)
        game.Players.LocalPlayer.Character.Humanoid.WalkSpeed = value
    end,
})

-- Runs once the user lets go (good for expensive work):
speed:OnRelease(function(value)
    print("Settled on", value)
end)

speed:SetRange(16, 500)
Option / MethodDescription
Min / MaxThe range. (Also Range = { min, max }.)
DefaultStarting value. (Also Value, CurrentValue.)
IncrementStep size. (Also Step, or Rounding for decimal places.)
SuffixText after the number, e.g. " studs" or "%".
:Set(value, silent)Sets the value (snapped to the increment).
:Get()Returns the value.
:SetRange(min, max)Changes the range and keeps the value inside it.
:OnRelease(fn)Runs when the user releases the slider.

Dropdown

Pick one option, or several with Multi = true. Single-select passes a string (or nil); multi-select passes an array.

local weapon = Tab:Dropdown({
    Name = "Weapon",
    Options = { "Sword", "Bow", "Staff" },
    Default = "Sword",
    Callback = function(choice)
        print("Picked", choice)
    end,
})

local function playerNames()
    local names = {}
    for _, p in ipairs(game.Players:GetPlayers()) do
        table.insert(names, p.Name)
    end
    return names
end

local targets = Tab:Dropdown({
    Name = "Targets",
    Options = playerNames(),
    Multi = true,
    Callback = function(list)
        print("Targets:", table.concat(list, ", "))
    end,
})

-- Keep the list fresh:
game.Players.PlayerAdded:Connect(function()
    targets:SetOptions(playerNames(), true)
end)
Option / MethodDescription
OptionsList of choices. (Also Values, List.)
DefaultStarting choice (or a list for multi). (Also Value, CurrentOption.)
MultiAllow several choices. (Also Multiple, MultipleOptions.)
AllowNoneLets a single-select be cleared.
PlaceholderText when nothing is selected. Default "Select...".
SearchShow a search box. Default: shown when there are more than 7 options.
MaxVisibleRows visible before scrolling. Default 6.
WidthWidth of the control.
:Set(value, silent) / :Get()Sets or reads the selection.
:SetOptions(list, keepSelection)Replaces the options. Alias Refresh.
:Add(option) / :Remove(option) / :Clear()Edits the option list.
:Open() / :Close()Opens or closes the list.
:Cycle(direction)Selects the next (1) or previous (-1) option.

Input

A text box. By default the callback runs when the user finishes typing.

Tab:Input({
    Name = "Target",
    Placeholder = "Username",
    Callback = function(text)
        print("Target set to", text)
    end,
})

Tab:Input({
    Name = "Amount",
    Numeric = true,      -- only numbers
    Live = true,         -- fire on every keystroke
    MaxLength = 6,
    Callback = function(text)
        print(tonumber(text))
    end,
})
Option / MethodDescription
DefaultStarting text. (Also Value, Text, CurrentValue.)
PlaceholderHint text. (Also PlaceholderText.)
NumericKeeps only numbers.
LiveFires on every keystroke. (Or Finished = false.)
MaxLengthMaximum characters.
ClearOnFocusEmpties the box when clicked.
WidthWidth of the box.
:Set(text, silent) / :Get()Sets or reads the text.
:Focus()Focuses the box.
:SetPlaceholder(text)Changes the hint text.

Keybind

A rebindable key. Click the key chip to rebind: the next key press becomes the bind, Escape cancels and Backspace clears.

-- Press: runs on every press
Tab:Keybind({
    Name = "Dash",
    Default = "Q",
    Callback = function()
        print("Dash!")
    end,
})

-- Toggle: each press flips a state
Tab:Keybind({
    Name = "Auto farm",
    Default = "G",
    Mode = "Toggle",
    Callback = function(on)
        print("Auto farm:", on)
    end,
})

-- Hold: true on press, false on release
Tab:Keybind({
    Name = "Aim",
    Default = "MouseButton2",
    Mode = "Hold",
    Callback = function(holding)
        print("Aiming:", holding)
    end,
}):OnBindChanged(function(key)
    print("Aim is now bound to", key and key.Name or "nothing")
end)
Option / MethodDescription
DefaultStarting key, e.g. "Q" or Enum.KeyCode.Q. (Also Key, Value, CurrentKeybind.)
Mode"Press" (default), "Toggle" or "Hold". (HoldToInteract = true means Hold.)
AllowMouseMouse buttons 2 and 3 can be bound. Default true.
:Set(key, silent) / :Get()Sets or reads the key. :Set(nil) clears it.
:Listen()Waits for the user to press a new key.
:OnBindChanged(fn)Runs when the user picks a different key.

Notifications

Toasts stacked bottom-right on desktop and top-center on touch devices. Hovering pauses the timer.

Aether:Notify({
    Title = "Saved",
    Content = "Config 'Legit' saved.",
    Type = "Success",   -- Info (default), Success, Warning, Error
    Duration = 4,       -- seconds; false keeps it until closed
})

-- With action buttons:
Aether:Notify({
    Title = "Teleported",
    Content = "You were moved to spawn.",
    Actions = {
        { Name = "Undo", Callback = function() print("undo") end },
    },
})

-- Update or dismiss it later:
local note = Aether:Notify({ Title = "Farming...", Duration = false })
task.wait(3)
note:Update({ Title = "Done!", Type = "Success", Duration = 3 })
OptionDescription
TitleHeading. (Also Name.)
ContentBody text. (Also Description, Text.)
Type"Info", "Success", "Warning" or "Error".
DurationSeconds. Default depends on text length. false never expires.
IconCustom icon. (Also Image.)
ActionsList of { Name, Callback } buttons.

The returned notification has :Update(options), :Dismiss() (alias Close) and a Dismissed signal.

Dialogs

A modal box with buttons. Clicking the dimmed background cancels unless Dismissible = false.

Window:Dialog({
    Title = "Unload?",
    Content = "This removes the interface.",
    Buttons = {
        { Name = "Cancel" },
        { Name = "Unload", Danger = true, Callback = function()
            Aether:Unload()
        end },
    },
})

Window:Dialog({
    Title = "Welcome!",
    Content = "Read the rules before using this script.",
    Dismissible = false,
    Buttons = {
        { Name = "I understand", Primary = true },
    },
})

Button styles: Primary = true uses the accent color, Danger = true uses red.

Key system

An optional key prompt. It yields until a valid key is entered (true) or the prompt is closed (false).

local unlocked = Aether:KeySystem({
    Title = "My Hub",
    Subtitle = "Key required",
    Note = "Join the Discord to get a key.",
    Link = "https://example.com/key",   -- "Get key" copies this
    Keys = { "AETHER-1234" },
    SaveKey = true,                     -- remember a valid key on this device
})
if not unlocked then return end

local Window = Aether:Window({ Name = "My Hub" })

Check keys your own way with Check:

Aether:KeySystem({
    Title = "My Hub",
    Check = function(key)
        return key:sub(1, 7) == "AETHER-" and #key == 11
    end,
})
Aether never contacts a server itself: keys are checked against Keys or your own Check function.

Flags

Give an element a Flag and its value is always available in Aether.Flags. The element itself is in Aether.Options.

Tab:Toggle({ Name = "Auto farm", Flag = "AutoFarm" })
Tab:Slider({ Name = "Delay", Min = 0, Max = 5, Default = 1, Flag = "FarmDelay" })

task.spawn(function()
    while task.wait(Aether.Flags.FarmDelay) do
        if Aether.Flags.AutoFarm then
            print("farming...")
        end
    end
end)

-- Change an element from anywhere:
Aether.Options.AutoFarm:Set(false)

Configs

Every element with a value is saved automatically, keyed by its Flag, or by "Tab/Section/Name" when it has none. Opt out per element with Save = false. Values for elements that don't exist yet are applied the moment the element is created, so loading never depends on timing.

Window:SaveConfig("Legit")
Window:LoadConfig("Legit")
Window:DeleteConfig("Legit")
print(Window:ListConfigs())   -- { "Legit", ... }

Window:SetAutoload("Legit")   -- load this one on every start

-- Share codes:
local code = Window:ExportConfig()
setclipboard(code)
Window:ImportConfig(code)

Or save everything automatically with AutoSave = true on the window.

Themes

Switching themes animates every color to the new palette.

Aether Midnight Ocean Rose Emerald Mono Light 
Aether:SetTheme("Ocean")

-- Tweak just a few colors:
Aether:SetTheme({ Accent = Color3.fromRGB(255, 120, 80) })

-- Register your own theme:
Aether:RegisterTheme("Sunset", {
    Accent = Color3.fromHex("#F97316"),
    AccentSecondary = Color3.fromHex("#EC4899"),
    Background = Color3.fromHex("#140B0B"),
})
Aether:SetTheme("Sunset")

print(Aether:GetThemes())

-- Share the current theme as a code:
local code = Aether:ExportTheme()   -- "AT1:..."
local ok, err = Aether:ImportTheme(code)

Theme keys

Accent, AccentSecondary, OnAccent, Background, BackgroundTransparency, Element, ElementTransparency, ElementHover, HoverTransparency, IndicatorTransparency, Control, Input, InputTransparency, Stroke, StrokeTransparency, Divider, DividerTransparency, Text, TextDim, TextMuted, Success, Warning, Danger, Shadow, GlowTransparency. Missing keys fall back to the default Aether theme.

Command palette

Press Ctrl + K (or the search button in the topbar) to fuzzy-search every element, tab and built-in command. Toggles flip in place, buttons press, and other elements are revealed. It even works while the window is hidden.

Window:OpenPalette()

-- Different key, or turn it off:
Aether:Window({ Name = "My Script", PaletteKey = "P" })
Aether:Window({ Name = "My Script", PaletteKey = false })

Pinned widgets

Small floating copies of elements that stay on screen (even while the window is hidden) and stay in sync with the original. Pin by dragging an element out of the window, from the right-click / long-press menu, or from code. Pins are remembered between sessions.

local fly = Tab:Toggle("Fly")
fly:Pin()                          -- default position
fly:Pin(Vector2.new(40, 200))      -- screen pixels
fly:Unpin()

Anywhere an Icon is accepted you can use a Lucide icon name, a numeric asset id, or a full rbxassetid:// string. Unknown names fall back gracefully.

Custom elements

Extend the base Aether.Element class and register it. Every tab and section then gets a method with that name.

local Element = Aether.Element

local Counter = Element.extend("Counter")
Counter.Saveable = true

function Counter.new(section, options)
    local self = setmetatable({}, Counter)
    Element.init(self, section, options, { Clickable = true })
    self:_publish(options.Default or 0)
    return Element._ready(self)
end

-- Clicking the row counts up.
function Counter:_onClick()
    self:Set(self.Value + 1)
end

function Counter:Set(value, silent)
    self:_publish(value)
    self:SetDescription("Count: " .. value)
    if not silent then
        self.Changed:Fire(value)
    end
    return self
end

Aether:RegisterElement("Counter", Counter)

Tab:Counter({ Name = "Clicks", Callback = print })

Rayfield compatibility

Scripts written for Rayfield run on Aether after changing the loadstring line. Window options like ConfigurationSaving, ToggleUIKeybind, KeySystem + KeySettings and Rayfield theme names are translated, and the Create* methods keep Rayfield's callback shapes.

local Rayfield = loadstring(game:HttpGet("https://raw.githubusercontent.com/RedScaleR/Aether/main/Aether.lua"))()

local Window = Rayfield:CreateWindow({
    Name = "My Hub",
    ConfigurationSaving = { Enabled = true, FolderName = "MyHub", FileName = "config" },
})

local Tab = Window:CreateTab("Main", "home")

Tab:CreateToggle({
    Name = "Fly",
    CurrentValue = false,
    Flag = "Fly",
    Callback = function(value) end,
})

Tab:CreateSlider({
    Name = "Speed",
    Range = { 16, 200 },
    Increment = 1,
    CurrentValue = 16,
    Flag = "Speed",
    Callback = function(value) end,
})

Rayfield:LoadConfiguration()
GrabKeyFromSite isn't supported, since Aether never downloads anything on its own. Put the keys in Key, or use Aether:KeySystem with a Check function.
